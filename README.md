Повноцінна інтеграція зарядних станцій FOSSiBOT у Home Assistant через хмарний API — телеметрія у реальному часі та повне керування виходами.

## 🔌 Підтримувані пристрої

| Модель | Статус |
|--------|--------|
| FOSSiBOT F1800 | ✅ Протестовано |
| Інші моделі з Fossibot+ | ⚠️ Можливо сумісні |

## ✨ Можливості

### 📊 Сенсори (Sensors)

| Назва | Entity ID | Одиниці | Опис |
|-------|-----------|---------|------|
| Battery | `sensor.*_battery` | % | Рівень заряду акумулятора |
| Temperature | `sensor.*_temperature` | °C | Температура станції |
| Time remaining | `sensor.*_time_remaining` | хв | Час до повного заряду або розряду |
| AC frequency | `sensor.*_ac_frequency` | Hz | Частота вихідного змінного струму |
| Output power | `sensor.*_output_power` | W | Поточна вихідна потужність |
| AC output voltage | `sensor.*_ac_output_voltage` | V | Напруга на виході AC (~230 В) |
| Charging | `sensor.*_charging` | — | Активний стан заряджання (1/0) |

> `*` = `fossibot_f180v012605b4936` (серійний номер вашої станції)

### 🎛️ Перемикачі (Switches)

| Назва | Entity ID | Опис |
|-------|-----------|------|
| AC output | `switch.*_ac_output` | Увімк./вимк. розеток змінного струму |
| DC output | `switch.*_dc_output` | Увімк./вимк. виходу постійного струму 12V |
| USB output | `switch.*_usb_output` | Увімк./вимк. USB-портів |

### 💡 Вибір режиму (Select)

| Назва | Entity ID | Опції |
|-------|-----------|-------|
| LED mode | `select.*_led_mode` | Off / Steady / SOS / Strobe |

## 🚀 Встановлення

### Через HACS (рекомендовано)

1. Відкрийте **HACS** → натисніть ⋮ → **Custom repositories**
2. Додайте `https://github.com/zelin-sky/ha-fossibot-plus` → категорія **Integration**
3. Знайдіть **FOSSiBOT Power Station** → натисніть **Download**
4. Перезапустіть Home Assistant

### Вручну

1. Скопіюйте папку `custom_components/fossibot_plus/` до `<config>/custom_components/`
2. Перезапустіть Home Assistant

### Налаштування

1. **Налаштування** → **Пристрої та служби** → **Додати інтеграцію**
2. Знайдіть **FOSSiBOT Power Station**
3. Введіть email та пароль від застосунку **Fossibot+**

## 📡 Технічні деталі

### Архітектура

```
Fossibot+ Cloud (app.fossibot.hk)
        │
        ├── POST /prod-api/app/user/login          JWT токен
        ├── GET  /prod-api/app/user_device/list    Список пристроїв + онлайн-статус
        ├── GET  /prod-api/app/ctrl/route           Команди керування
        └── WS   ws://app.fossibot.hk/ws           Телеметрія (~1 кадр/сек)
                        │
                        ▼
            custom_components/fossibot_plus/
```

### Протокол телеметрії

Сервер надсилає бінарні TLV-кадри (tag + value) через WebSocket приблизно раз на секунду. Кожен кадр містить усі показники станції.

**Формат кадру:**
```
[6 байт заголовок][N × (2 байти тег + 4 байти значення LE)][2 байти CRC16]
```

### Підтверджені теги TLV

| Тег | Значення | Scale | Опис |
|-----|----------|-------|------|
| `0100` | uint32 | ×1 | SOC (%) |
| `0200` | uint32 | ×1 | Температура (°C) |
| `0300` | uint32 | ×1 | Залишок часу (хвилини) |
| `0400` | 0/1 | — | Заряджання активне |
| `1300` | uint32 | ×1 | Вхідна потужність при зарядці (Вт) |
| `1400` | uint32 | ×1 | Вихідна потужність (Вт) |
| `1500` | uint32 | ×0.1 | Вихідна напруга AC (В, ~230 В) |
| `1600` | uint32 | ×0.1 | Частота AC (Гц) |
| `2600` | 0-3 | — | LED: 0=вимк, 1=постійний, 2=SOS, 3=строб |
| `2700` | 0/1 | — | AC вихід вмк/вимк |
| `2800` | 0/1 | — | DC вихід вмк/вимк |
| `2900` | 0/1 | — | USB вихід вмк/вимк |

### Формат команди керування

```
cmd = "0e000c000800" + tag(2B LE) + value(4B LE) + CRC16/MODBUS(tag+value, big-endian)
GET /prod-api/app/ctrl/route?snCode=<SN>&cmd=<cmd>
```

CRC підтверджено для всіх 10 перехоплених команд (AC/DC/USB/LED).

### Онлайн/Офлайн статус

Стан пристрою (`state: true/false`) опитується через REST кожну хвилину. При офлайн-статусі всі сутності переходять в `unavailable`.

### Надійність з'єднання

- **Watchdog**: якщо WS мовчить >30 с — автоматичне перепідключення
- **Heartbeat**: `{"type":"hear","msg":"<email>"}` кожні 5 с
- **Anti-duplicate guard**: сервер захищений від повторних логінів — реалізовано ретрай із паузою 6 с
- **Token refresh**: автоматичний перелогін при `401`

## 🛠️ Розробка та реверс-інжиніринг

Інтеграція розроблена методом аналізу реального трафіку (Charles Proxy) між офіційним застосунком Fossibot+ та хмарою. Теги TLV підтверджено шляхом порівняння значень у WS-кадрах із показниками на екрані застосунку в той самий момент часу.

### Debug logging

```yaml
logger:
  default: warning
  logs:
    custom_components.fossibot_plus: debug
```

Кожен WS-кадр логується як:
```
FOSSiBOT <snCode> frame: raw=e0000b00... decoded={'0100': 67, '0200': 22, ...}
```

### Статус підтвердження сенсорів

| Статус | Значення |
|--------|----------|
| ✅ Підтверджено | Значення звірено з екраном застосунку в один момент часу |
| 🔶 Кандидат | Сильна кореляція, але без прямого підтвердження |
| ❌ Спростовано | Початкове припущення виявилось невірним |

> Файл `DEVELOPMENT.md` у репозиторії містить детальну таблицю всіх тегів, включно зі спростованими і невідомими.

## 📋 Відомі обмеження

- Вхідна потужність при зарядці (`1300`) та вхідна напруга (`2a00`) відображаються як "кандидати" — підтверджено непрямо
- ~15 невідомих тегів у кадрі поки не розшифровані
- API не підтримує HTTPS (звичайний HTTP на порту 80)
- Команди керування відправляються через GET-запит (особливість API)
